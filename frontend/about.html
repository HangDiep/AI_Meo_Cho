Project Overview

The AI Mask Detection System is a smart computer vision project developed to detect face mask usage in realtime using Artificial Intelligence, Deep Learning, and Computer Vision technologies.

This system is capable of analyzing faces directly from webcam streams and uploaded images to determine whether a person is:

  • Wearing a face mask correctly
  • Not wearing a face mask
  • Wearing a mask incorrectly

The project combines TensorFlow, OpenCV, Flask, and Deep Learning models to build an intelligent monitoring system that can be applied in schools, hospitals, offices, and public environments for health safety support.

In addition to realtime detection, the system also supports image upload prediction, live statistics visualization, and a modern responsive dashboard interface.
